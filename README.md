# Álgebra Lab

Aplicación educativa en español para practicar matrices, sistemas de ecuaciones y vectores.

## Abrir la aplicación

Descargá o cloná este repositorio y abrí `index.html` en tu navegador. No requiere instalación, dependencias ni servidor.

## Contenido

- Matrices: suma, resta, multiplicación, submatrices, determinantes e inversa.
- Sistemas de 2 a 10 incógnitas: Gauss-Jordan, Gauss, Cramer y matriz inversa. Para 2 incógnitas: sustitución, igualación y reducción.
- Vectores: suma, resta, multiplicación por escalar, producto punto y producto cruz.
- Aplicaciones: trabajo, ángulos, proyecciones, áreas, normales y torque.
- Guía de estudio con ejercicios y respuestas.

## Archivos

- `index.html`: interfaz y estilos adaptables a celular y computadora.
- `app.js`: calculadoras, procedimientos, visualización y contenidos.

## Uso

Separá columnas con espacios y filas con saltos de línea. Usá punto para decimales. Los resultados se redondean a 6 decimales. Las operaciones usan aritmética numérica aproximada; el producto cruz requiere tres componentes y la gráfica muestra su proyección XY.
